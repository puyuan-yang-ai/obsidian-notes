@dataclass 是干什么的？	@dataclass 是 Python 的一个装饰器，它会自动生成 __init__ 方法，根据类中定义的字段和默认值来初始化对象。
"@dataclass class 父类:     name: str = ""默认名字""  class 子类(父类):     name: str = ""自定义名字""  # 创建对象时 obj = 子类() print(obj.name)  这时候输出结果是什么以及为什么 ？"	"# 输出：默认名字 ← 用的是父类的默认值！因为子类没有 @dataclass"
没有 @dataclass：子类为什么会使用父类的默认值？	因为子类没有自己的 __init__，调用父类的 __init__，进而使用父类的默认值

mini-swe-agent通过environment的方式结合了mcp，进行了2次调用，第一次是ai-devtool mcp server，第二次才是走http请求来访问llm api，是吗？	"是不准确的，顺序是：LLM → MCP → LLM，不是 MCP → LLM。 具体如下：   用户输入任务     ↓ 第 1 次 HTTP 请求 → LLM API → LLM 返回 ""@amd:query {...}""     ↓ Agent 执行命令 → 调用 MCP Server → 获取结果     ↓ 第 2 次 HTTP 请求 → LLM API → LLM 基于结果生成总结     ↓ 返回给用户"
