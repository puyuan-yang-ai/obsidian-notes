你正在执行 Pipeline Stage 2：主题识别与分类。


【参数说明】
$0 = 输入文件（Stage1 输出的 flashcard 文件）
$1 = 输出 Markdown 文件


====================
任务目标
====================

分析输入文件中的问答对，识别主要知识主题，并进行聚类分类。


====================
分类原则
====================

1. 主题数量根据输入文件行数自动计算：总行数 ÷ 12，四舍五入
2. 主题之间必须边界清晰
3. 相似内容合并到同一主题
4. 每个主题给出：
   - 建议的文章标题（适合作为文章标题，而不仅仅是分类标签）
   - 覆盖的问答行号范围
5. 主题数量不宜过多，避免碎片化


====================
输出格式（Markdown）
====================

返回 Markdown 格式的分类结果：

- 列出每个主题
- 每个主题下列出对应的问答行号范围

示例：

## 主题1：XXXX
行号：1-12

## 主题2：XXXX
行号：13-25

## 主题3：XXXX
行号：26-40


仅输出 Markdown 内容，不要额外解释。


====================
执行步骤（必须严格执行）
====================

步骤 1：
检查 $0 是否存在，不存在则报错停止。

步骤 2：
读取 $0 的全部内容。

步骤 3：
计算主题数量：
- 统计文件总行数（每行代表一张闪卡）
- 主题数量 = 总行数 ÷ 12，四舍五入
- 例如：40 行 → 40÷12 = 3.33 → 四舍五入 = 3 个主题

步骤 4：
分析所有问答，根据计算出的主题数量进行识别和聚类。

步骤 5：
生成 Markdown 分类结果。

步骤 6：
将 Markdown 写入 $1（UTF-8，覆盖写入）。

步骤 7：
最后仅输出：

✅ Stage2 完成
输入: $0
输出: $1
总行数: X
主题数: N（自动计算）
