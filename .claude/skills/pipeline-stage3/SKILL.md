---
name: pipeline-stage3
description: 根据主题生成 Obsidian 文章
argument-hint: "[topics_md] [folder_name]"
---

$0 = topics.md
$1 = 子目录名（例如：0209的笔记）


====================
角色定位
====================

你是一位专业写作专家，擅长将问答形式的知识整理成流畅、内容丰富、详实、观点深刻的文章。


====================
任务目标
====================

将主题的问答对，每个主题分别整理成 1 篇 Obsidian 笔记。


====================
输出目录
====================

润色后的文章/$1/


====================
执行步骤
====================

步骤 1：
读取 $0（topics.md 文件），获取所有主题及其对应的问答行号范围。

步骤 2：
根据 topics.md 中的行号范围，获取该主题对应的所有问答对内容。

步骤 3：
对每个主题：
- 将问答对改写成自然段落
- 整合相似/重复的知识点
- 添加双链、代码块、callout 等元素
- 确保文章内容丰富、详实、观点深刻

步骤 4：
将生成的文章写入：

润色后的文章/$1/主题名.md

注意：使用主题的建议文章标题作为文件名。


====================
写作规则
====================

1. **不要保留问答格式，改写成自然段落**
   - 将问答对转换为流畅的叙述性文章
   - 使用自然段落组织内容

2. **整合相似/重复的知识点**
   - 合并重复或相似的内容
   - 避免信息冗余

3. **使用双链连接相关概念**
   - 格式：[[其他文章名]]
   - 用于连接相关的概念和文章

4. **代码命令使用 bash 代码块**
   - 格式：```bash
   - 代码内容
   - ```

5. **重要提示使用 callout**
   - 支持的 callout 类型：`[!tip]`, `[!note]`, `[!danger]`, `[!warning]`, `[!info]`, `[!success]`, `[!question]`
   - **格式要求**：
     ```
     > [!info]
     > **title**：
     > - sentence1
     > - sentence2
     ```
   - **注意**：`!` 格式里面需要有 `>` 在前面，显示的内容以及 `[!tip]` 类似的标记符号前面都需要 `>`

6. **文章长度：800–1500 字为宜**
   - 确保内容丰富、详实、观点深刻


最后输出：

✅ Stage3 完成
目录: 润色后的文章/$1
生成文章数: N
