# 交易执行与技术指标：从波动率到智能挂单

## True Range（TR）：真实波幅的全面衡量

在设置买入挂单时，我们需要准确衡量资产的波动性。**True Range（TR，真实波幅）** 是衡量整体波动率的核心指标。

### TR的计算方式

TR的计算考虑了三种可能的波动情况：

```bash
TR = max(
    当日最高价 - 当日最低价,    # 日内波动
    |当日最高价 - 昨日收盘价|,   # 向上跳空
    |当日最低价 - 昨日收盘价|    # 向下跳空
)
```

> [!info]
> **TR涵盖的三种场景**
> - **日内波动**：当日最高价与最低价之差
> - **向上跳空**：今日开盘跳空高开
> - **向下跳空**：今日开盘跳空低开

### ATR：平均真实波幅

**ATR（Average True Range）** 是TR的N日平均值，通常N取14：

```bash
ATR = TR的14日平均值
```

ATR是双向指标，同时考虑上涨和下跌的波动幅度。

## 向下波动统计：单向挂单的精准工具

当我们基于昨日收盘价计算"今日能跌多少"来设置买入挂单时，ATR并不适用——因为ATR是双向的，而我们需要的是单向的下跌波幅。

### 向下波幅计算公式

```bash
向下波幅 = max(0, (昨日收盘价 - 今日最低价) / 昨日收盘价)
```

> [!tip]
> **为什么使用昨日收盘价而非今日开盘价？**
> - 昨日收盘是交易开始前的"公认基准"
> - 主流指标ATR也基于昨日收盘价
> - **关键优势**：基于昨日收盘能考虑跳空情况，而基于今日开盘价无法考虑跳空

## 三档挂单设计：平衡成交概率与成本

智能挂单的核心是设计合理的档位，既保证足够的成交概率，又避免在极端行情中过早成交。

### 三档挂单逻辑

```bash
第一档 = 30%分位数（预期70%成交）
第二档 = 60%分位数（预期40%成交）
第三档 = 最大跌幅 × 90%（抓极端行情）
```

> [!question]
> **为什么第三档不是90%分位数，而是最大跌幅×90%？**

**答案**：为应对突然暴跌。

- 如果突然暴跌10%后继续跌，90%分位数可能只有4%
- 第三档4%成交后，市场继续跌到10%
- 正常时期大部分天跌幅1-3%，突然暴跌某天跌10%，后续继续跌8-10%
- **用90%分位数会很快成交但市场还在继续跌**

### 档位设计原理

> [!info]
> **三档挂单的设计理念**
> - **第一档、第二档**：基于"正常波动"设计，用百分位数合理
> - **第三档**：用于抓"极端行情"，必须和"极端值"挂钩

### 百分位数的统计学意义

**X%分位数**的含义：X%的天数跌幅≤这个值。

挂在X%分位数位置，统计学意义是：有(100-X)%的概率能跌到这个位置，即**成交率≈(100-X)%**。

**示例**：14天数据的70%分位数=3.1%

- 含义：14天中70%的天数跌幅≤3.1%
- 挂单逻辑：挂在跌3.1%位置，有约**30%**（不是70%）概率能成交

## 传统挂单方式的改进

### 方式一：分箱众数法

**原来方式**：第一档=众数区间下限（如2-3%区间取2%）

**缺点**：
1. 分箱粒度人为设定（用1%分箱vs 0.5%分箱结果可能不同）
2. 不够通用（业界很少用）

**改进点**：使用百分位数，任意X%分位数灵活可调风险偏好，需要选择合适百分位。

### 方式二：固定趋势档位

**原来方式**：固定趋势档位（上涨3%、下跌5%）

**逻辑**：上涨趋势中更容易接到回调，下跌趋势中成本更低。

**缺点**：人为设定，灵活程度低（固定值）。

**改进点**：**波动率动态档位**，根据近14天实际波动自动调整：

```bash
高波动期 → 档位自动拉宽
低波动期 → 档位自动收窄
```

## 仓位分布策略：量化机构的四种方案

当设置多档挂单时，每档分配多少仓位？量化机构通常采用以下四种方案：

| 策略 | 比例分布 | 特点 |
|------|----------|------|
| **等额分配** | 1:1:1:1 | 最简单无偏见 |
| **等比递增** | 1:2:3:4 | 正金字塔，越远越重 |
| **等比递减** | 4:3:2:1 | 倒金字塔，越近越重 |
| **指数递增** | 1:2:4:8 | 激进正金字塔 |

> [!note]
> **选择建议**
> - 保守投资者：等额分配或等比递减
> - 中性投资者：等比递增
> - 激进投资者：指数递增

## 结语

交易执行是将投资策略落地的关键环节。通过TR/ATR理解资产波动性，通过向下波幅统计设计精准挂单，通过三档挂单平衡成交概率与成本，通过仓位分布优化资金利用效率——这些技术工具共同构成了智能交易系统的基础。

> [!success]
> **核心要点**
> - TR衡量双向波动，向下波幅衡量单向下跌
> - 三档挂单：前两档用百分位数抓正常波动，第三档用极端值抓暴跌
> - 动态档位优于固定档位，自动适应市场波动变化
> - 仓位分布需根据风险偏好选择合适的分配策略
