# SFT 训练中的 Loss 与学习率优化策略

在监督微调（SFT）的训练过程中，Loss 的变化趋势和学习率的调度策略是模型收敛的关键。本文将深入探讨 SFT 训练中 loss 的计算原理、影响因素，以及学习率优化的核心策略。

## Loss 的计算原理与直觉理解

SFT 使用的是**交叉熵损失（Cross-Entropy Loss）**，本质上是一个语言模型的下一个 token 预测任务。具体来说：

1. 给模型一段文本，让它预测每个位置的下一个 token
2. 模型输出一个概率分布（词表大小，如 151,936 维的向量）
3. Loss 衡量的是：模型给"正确答案"分配的概率有多高

通过数学公式 `loss = -log(P(正确token))` 可以直观理解：

- 如果正确 token 的概率是 **0.9**，loss = -log(0.9) ≈ **0.105**（很小，说明模型很确信）
- 如果正确 token 的概率是 **0.1**，loss = -log(0.1) ≈ **2.303**（很大，说明模型不确定）
- 如果正确 token 的概率是 **0.01**，loss = -log(0.01) ≈ **4.605**（非常大，几乎猜错了）

> [!info]
> **SFT 的特殊之处**：
> 通常只在 assistant 回答部分计算 loss，不在 system prompt 和 user 输入部分计算（通过 label masking 实现），因为我们只关心模型"回答"的质量。

## Loss 的合理范围与影响因素

"初始 loss ~2.0-3.0，最终 ~1.0-1.5" 这一范围在 SFT 训练中具有一定的普遍性，但并非绝对。经过预训练的模型已经很懂语言了，SFT 初始 loss 通常在 **1.5-3.0** 之间。训练结束后：

- **loss < 0.5**：几乎在所有场景下都意味着过拟合
- **loss 在 0.8-1.5 之间**：通常是健康的范围

影响 loss 绝对值的因素主要有以下几个维度：

### 1. 模型大小
大模型初始 loss 通常更低，因为预训练阶段学得更好。小模型可能需要更长的训练时间才能达到相似的 loss 水平。

### 2. 数据质量
高质量、一致性强的数据能让 loss 更容易降低。如果数据中存在大量噪声、矛盾或低质量样本，loss 会难以下降。

### 3. 任务复杂度
简单分类任务的 loss 可以降得很低，而开放式生成任务由于答案空间巨大，loss 很难降到很低。

### 4. 数据多样性
数据越多样，loss 越难降得特别低（但泛化能力更好）。如果数据过于单一，loss 可以降得很低，但容易过拟合。

## 学习率调度：Warmup + 余弦衰减

学习率从 0 线性 warmup 到峰值（如 2e-4），再按余弦曲线衰减到 0，这是 SFT 的**默认最佳实践**，绝大多数情况下不需要修改。

### Warmup 阶段的作用

训练初期，模型参数处于随机/预训练状态，梯度方向不稳定。如果一开始就用大学习率，可能导致参数剧烈震荡甚至训练崩溃。Warmup 让模型先用小步子"探路"，找到合理的梯度方向后再加速。

### 余弦衰减阶段的作用

训练后期，模型已接近最优点，需要减小步长来精细调整。余弦衰减比线性衰减更"温和"——前期衰减慢（充分学习），后期衰减快（精细收敛）。

> [!tip]
> **调度策略的调整原则**：
> 策略（warmup + cosine）一般不改，调的是**峰值大小**和 **warmup 比例**。

## 不同场景下的学习率调整建议

虽然调度策略不变，但峰值学习率需要根据具体情况调整：

| 场景 | 调整建议 | 原因 |
|------|----------|------|
| 训练初期 loss 震荡剧烈 | 增加 warmup steps（如从 3% → 10%） | 给模型更长的"探路"时间 |
| 训练收敛太慢 | 提高峰值学习率（如 2e-4 → 5e-4） | 加大步长加速收敛 |
| 换了更大的模型 | 降低峰值学习率（如 7B 模型用 1e-4 或 5e-5） | 大模型对学习率更敏感 |
| 数据集很小（< 1000 条） | 降低学习率 + 减少 epoch | 防止过拟合 |

## 线性缩放规则（Linear Scaling Rule）

线性缩放规则是深度学习中的一个经验法则：**batch size 翻 k 倍 → 学习率也翻 k 倍**。

例如：
- bs=16, lr=2e-4 → bs=32, lr=4e-4
- bs=16, lr=2e-4 → bs=8, lr=1e-4

### 直觉理解

想象你在山上下坡（梯度下降）：

- **小 batch（如 bs=4）**：你只看了 4 个方向的信息来决定往哪走，信息少，估计不太准 → 应该走小步（小学习率），防止走错
- **大 batch（如 bs=64）**：你看了 64 个方向的信息，估计很准确 → 可以放心走大步（大学习率）

### 数学解释

梯度是随机采样的，batch 越大，梯度估计的方差越小：

```
梯度方差 ∝ 1 / batch_size
```

方差小 → 梯度方向更可靠 → 可以用更大的学习率

> [!warning]
> **注意事项**：
> - 线性缩放是**经验规则**，不是严格定律
> - 当 batch size 变化时，学习率调度模式（warmup + cosine decay）不变，变的只是**峰值学习率的大小**
> - 曲线的"形状"不变，但"高度"变了

## 关键要点总结

理解 SFT 训练中的 loss 计算和学习率优化策略，可以帮助你：

1. **判断训练状态**：通过 loss 的绝对值和变化趋势，识别欠拟合、正常收敛或过拟合
2. **合理调整超参数**：根据具体场景（模型大小、数据量、训练速度）调整峰值学习率和 warmup 比例
3. **优化训练效率**：理解 batch size 与学习率的关系，在显存和训练速度之间找到平衡

记住：**Warmup + 余弦衰减**是 SFT 的最佳实践，大部分情况下只需要调整峰值大小，而不需要改变整体策略。
