# tmux 原理篇：理解终端复用与持久化会话机制

## 什么是终端复用器

tmux 的全称是 **Terminal Multiplexer**，即终端复用器。它允许在一个终端窗口中同时管理多个"子终端"（会话/窗口），即使断开连接，这些会话也继续运行，你可以随时再连回来接着用。

> [!info]
> **tmux vs screen**
> - **screen**：老牌、稳定的终端复用工具
> - **tmux**：更现代的替代品，被认为是 screen 的继任者，功能更丰富

## 持久化会话的核心价值

使用 tmux 或 screen 创建持久化会话的最大好处是：**即使 SSH 断开，会话和其中的命令也会继续在后台运行，不会中断。**

这是一个非常实用的特性。想象一下这样的场景：你在远程服务器上运行一个耗时的 `docker build`，如果直接在 SSH 连接中运行，一旦网络波动或你关闭 SSH 窗口，构建过程就会被中断。而使用 tmux 后再运行，这个程序是在独立的、持久化的会话中运行，而不是直接依赖于你的 SSH 连接。即使 SSH 掉线，构建也会继续执行。

> [!tip]
> **判断是否需要使用 tmux**
> 满足以下两个条件之一就应该使用 tmux：
> - 在远程服务器或容器里执行
> - 脚本预计运行超过几十秒，且你在乎它的结果或日志

反之，如果只是执行快速的 Linux 小命令，或者只跑 1～2 秒的测试脚本，完全不用 tmux。

## 深入理解：为什么 tmux 会话能持久化

### SIGHUP 信号机制

当 SSH 断开时，shell 会收到 **SIGHUP** 信号（挂起信号），导致 shell 退出，从而其中运行的程序也被中断。这是 Linux 终端的默认行为。

### tmux server 守护进程

tmux 巧妙地绕过了这个问题。当你第一次在服务器上运行 tmux 时，会启动一个 **tmux server 进程**。这个进程是一个**守护进程**（Daemon），它的父进程是系统的初始进程（init 或 systemd），而不是你的 SSH 登录 Shell。

```bash
# 在 tmux 里运行 python xxx.py 的进程树
系统总管 (systemd) -> tmux server -> (在tmux里的) bash -> python xxx.py
```

> [!note]
> **tmux server 独立于 SSH 会话**
>
> 因为 tmux server 是独立于任何 SSH 登录会话的守护进程，即使你退出 SSH，tmux server 依然会在后台运行，保持会话存在。

当在 tmux 中运行程序时，SSH 断开时发送的 SIGHUP 信号**不会影响** tmux server 以及它的子进程。SIGHUP 只会影响你登录时的那个交互式 Shell，而 tmux server 是独立的守护进程，不受 SSH 断开影响，它和其中的子进程都会继续运行。

## 会话持久化的边界

需要注意的是，tmux 会话的持久化是有边界的：

> [!warning]
> **服务器重启会导致会话丢失**
>
> tmux 会话本质上是内存中的进程，服务器重启后内存清空，所有 tmux 会话都会丢失。因此 tmux 解决的是"网络断线"问题，而不是"服务器重启"问题。

## 前缀键机制：区分输入与控制

tmux 中有一个核心概念叫**前缀键**（Prefix Key）。默认情况下，tmux 的前缀键是 `Ctrl + b`。

### 为什么需要前缀键

前缀键的作用是告诉 tmux："接下来我要输入控制命令"。按下前缀键后，tmux 才会把下一个按键当作控制指令来执行。

- **普通输入**：直接发送给当前 pane 的 shell，比如输入命令或运行程序
- **控制命令**：用来操作 tmux 自身的，比如分屏、切换窗口、关闭 pane 等

区别在于——普通输入作用在"终端里的程序"，控制命令作用在"tmux 本身"。

> [!question]
> **为什么是 Ctrl + b？**
>
> Ctrl + b 是 tmux 的默认前缀键，表示"告诉 tmux 我接下来要输入控制命令"。b 没有特别含义，只是历史上作者选择了它作为默认前缀（因为 Emacs 中 Ctrl + b 是向后移动字符，在 tmux 开发的年代不太常用）。

## 小结

tmux 通过创建独立的守护进程（tmux server），将用户的工作会话与 SSH 连接解耦，从而实现了会话的持久化。这使得在远程服务器上进行长时间任务时，不再需要担心网络波动导致的任务中断。配合前缀键机制，tmux 提供了一套完整的终端复用解决方案。
