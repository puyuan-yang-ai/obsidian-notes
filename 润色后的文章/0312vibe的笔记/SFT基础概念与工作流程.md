# SFT 基础概念与工作流程

## SFT 的核心思路

Supervised Fine-Tuning (SFT) 是大模型训练中的关键环节，其核心思路是：拿一个已经预训练好的大语言模型（如 Qwen1.5-0.5B），用"指令-回答"格式的数据集（如中文 Alpaca）来教它遵循指令，并用 LoRA 只训练模型的一小部分参数以节省显存和时间。训练完成后，模型就学会了"看到指令 → 生成回答"的能力。

这个过程的意义在于让模型从"会写字"变成"会对话"，从单纯的文本续写能力升级为理解和执行指令的能力。

## 最小闭环与核心文件

一个完整的 SFT 最小闭环包括三个步骤：训练 → 保存 adapter/模型 → 推理验证。要实现这个闭环，最小可运行的 SFT demo 只需要两个核心文件：

- `train.py`：负责训练过程
- `inference.py`：负责加载训练结果进行测试

这两个文件构成了 SFT 的完整生命周期。

## 标准训练流程

标准的 SFT + LoRA 训练流程遵循以下步骤：

1. **加载数据集**：获取"指令-回答"格式的训练数据
2. **Tokenizer 处理**：将文本转换为模型可识别的数字序列
3. **加载预训练模型**：导入已完成预训练的基础模型
4. **套上 LoRA 适配器**：在模型关键层添加参数高效的适配器
5. **启动训练**：使用 Trainer 进行自动化训练

整个流程可以表示为：加载数据集 → Tokenizer 处理文本 → 加载预训练模型 → 给模型套上 LoRA 适配器 → 用 Trainer 启动训练。

## 数据集格式

经典的 instruction-following 数据集通常包含三个字段：

- **instruction**：指令内容
- **input**：输入上下文（可选）
- **output**：期望的回答

这种结构化的数据格式为模型提供了清晰的学习目标。

## Tokenizer 的作用

Tokenizer 在训练中扮演着关键角色，它的作用是把文字转换成数字。这一步至关重要，因为模型本身不认识文字，只认识数字序列。每个文本都需要经过 Tokenizer 转换为 token id，然后才能被模型处理。

> [!warning]
> **Tokenizer 和 Model 必须一致**：
> - Tokenizer 负责把文字转成 token id
> - Model 的 embedding layer 有一张词表，每个 id 对应一个向量
> - 如果两者不一致，tokenizer 产出的 id 在 model 的 embedding 里找不到对应向量，训练会报错或输出乱码

## LoRA 核心机制

LoRA（Low-Rank Adaptation）的核心思想是不修改原始模型，只在关键层旁边加一个"小旁路"。这样做的效果是只需训练很少的参数，通常少于原始参数量的 1%。

### LoRA 的关键参数

- **r（秩）**：代表 LoRA 的秩，越大能力越强但参数越多，常用值为 8、16 或 32
- **alpha**：缩放系数，通常设为 r 的 2 倍
- **dropout**：用于防止过拟合

### LoRA 训练后的保存与使用

LoRA 训练后保存的不是完整模型，而只是 LoRA 适配器权重，文件很小。推理时需要：加载原始模型 + 加载 LoRA 权重 = 完整模型。这种方式大大节省了存储空间。

## Teacher Forcing 机制

在 SFT 训练中，teacher forcing 对单个问答对的训练不是只走一步。实际上，一个回答有 N 个 token 就会训练 N 步。例如，如果回答包含 5 个 token，就会进行 5 次预测，每次预测都会执行前向传播并反向更新梯度。

训练时，模型每一步吃的不是自己刚生成的词，而是真实答案中的前文 token。这种机制确保了训练的稳定性和效率。

## 训练质量判断

判断 SFT 训练好坏有几个关键指标：

1. **Loss 下降趋势**：loss 应该整体呈下降趋势，初始值约 2-3，最终希望小于 1.5
2. **避免过拟合**：loss 不应该降到 0，那可能是过拟合（死记硬背）
3. **学习率适配**：如果 loss 一直不降或震荡，可能是学习率太大或太小
4. **实际效果验证**：最终效果还要看模型生成的回答质量，使用 inference.py 测试实际回答是否合理

> [!tip]
> **Loss 不是唯一标准**：
> - Loss 只是数学指标，不能完全反映模型的实际能力
> - 训练完成后一定要用 inference.py 问几个问题，看回答是否合理
> - 有时 loss 看起来不错，但实际生成质量可能不理想
