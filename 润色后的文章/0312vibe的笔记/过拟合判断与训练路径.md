# 过拟合判断与训练路径

## 数据量与模型大小的关系

在 SFT 训练中，数据量和模型大小并没有固定的比例关系，这与很多人的直觉相反。

### 为什么 8B 模型用 30K 数据也可以？

关键在于理解 SFT 的本质：SFT 不是让模型"从零学知识"，而是"调整行为模式"。

- 8B 模型在预训练阶段已经学习了大量知识
- SFT 只是教它"怎么用这些知识来回答问题"
- 这种"行为调整"不需要海量数据
- 几千到几万条高质量数据就足够了

### 0.5B 模型用 52K 数据会过拟合吗？

从训练结果来看，0.5B 模型最终 loss 为 1.66，还不算特别低（没有趋近于 0），所以轻微过拟合可能存在，但不严重。

## 准确判断过拟合的方法

判断过拟合最可靠的方法是观察 `eval_loss` 的变化趋势。

### 正确的判断流程

```
train_loss:  2.4 → 1.7 → 1.5 → 1.3  (一直降)
eval_loss:   2.4 → 1.8 → 1.7 → 1.9  (先降后升 ← 过拟合信号!)
```

当 train_loss 继续下降但 eval_loss 开始上升时，说明模型在"死记硬背"训练集而没有学到泛化能力。这是过拟合最明确的信号。

> [!warning]
> **单看 train_loss 不够**：
> - 仅观察 train_loss 可能错过过拟合的早期信号
> - 必须同时监控 eval_loss 的变化
> - 在 eval_loss 开始上升时及时停止训练

## 大模型训练的标准路径

理解 SFT 在整个大模型训练流程中的位置，有助于更好地把握训练目标。大模型训练通常遵循四个阶段：

### 1. PT (Pre-Training) - 预训练

- **训练方式**：从零开始，在万亿 token 上训练
- **学习目标**：语言理解 + 文本续写
- **Loss 计算**：全句都算 loss

### 2. CPT (Continual Pre-Training) - 持续预训练（可选）

- **训练方式**：在特定领域数据上继续预训练
- **学习目标**：领域知识（如医学、法律、代码）

### 3. SFT (Supervised Fine-Tuning) - 监督微调

- **训练方式**：在"指令-回答"数据上微调
- **学习目标**：指令遵循 + 对话格式
- **Loss 计算**：只算回答部分 loss

这是本文讨论的主要阶段，也是让模型从"会续写"变成"会对话"的关键步骤。

### 4. RLHF / DPO（可选）

- **训练方式**：用人类偏好数据进一步优化
- **学习目标**：更安全、更有帮助、更符合人类期望的回答

## LoRA Target Modules 详解

在使用 LoRA 进行 SFT 时，`target_modules` 字段指定了要添加适配器的层。典型配置包含 7 个参数：

### Transformer 层结构

```
Transformer Layer
├── Self-Attention (自注意力机制)
│   ├── q_proj  → Query 投影矩阵 (把输入变成"我在找什么")
│   ├── k_proj  → Key 投影矩阵 (把输入变成"我有什么")
│   ├── v_proj  → Value 投影矩阵 (把输入变成"我的内容是什么")
│   └── o_proj  → Output 投影矩阵 (把注意力结果映射回去)
│
└── FFN (前馈网络, 也叫 MLP)
    ├── gate_proj  → 门控层 (决定哪些信息通过)
    ├── up_proj    → 上投影 (扩展维度，提取特征)
    └── down_proj  → 下投影 (压缩维度，输出结果)
```

### 为什么选这 7 个层？

这些是 Transformer 模型内部具体的线性层名称，LoRA 就是在这些层上加"旁路"。选择这 7 个层是因为：

- 它们是模型中参数最多的线性层
- 对模型的表达能力影响最大
- 给这些层加 LoRA 旁路，性价比最高

## 学习率调度策略

学习率的变化曲线对训练效果有重要影响。三个参数共同决定学习率曲线的形状。

### 决定学习率曲线的三个参数

1. **learning_rate**：决定曲线的最高点
2. **warmup_ratio**：决定上升阶段有多长
3. **lr_scheduler_type**：决定下降阶段的形状（余弦、线性、恒定等）

### 常见的学习率模式

典型的学习率变化模式是：先快速上升到峰值，然后按余弦曲线缓慢下降到接近 0。

### 具体配置示例

```python
warmup_ratio=0.05
lr_scheduler_type="cosine"
learning_rate=2e-4
```

这组配置的含义是：

- **warmup_ratio=0.05**：前 5% 的步数（约 488 步），学习率从 0 线性升到 2e-4
- **lr_scheduler_type="cosine"**：从第 488 步开始，按余弦曲线平滑下降
- **learning_rate=2e-4**：学习率的最高点，最终降到接近 0

对应的曲线形状：先快速上升（左侧陡峭部分），到达顶点后，按余弦曲线缓慢下降到 0。

> [!tip]
> **学习率调度的重要性**：
> - Warmup 阶段避免训练初期梯度过大导致的不稳定
> - 余弦下降使得训练后期能更精细地调整参数
> - 这种调度策略已被证明在大多数场景下效果良好

## 预训练模型 vs SFT 模型

理解两者的区别，有助于明确 SFT 的训练目标。

### 仅预训练的原始模型

- **能力**：会"续写"文本，但不太会"遵循指令"
- **表现**：回答可能跑题、太短或格式混乱
- **本质**：只会做一件事——根据前文预测后面最可能出现的文字

### 典型的差回答示例

仅预训练的模型收到问题后，可能把用户问题当成"题目列表的开头"，然后续写更多题目，而不是回答问题。这是因为它根本不具备"回答问题"这个能力。

有时看起来像在回答（例如让 AI 写关于春天的诗，原始模型写得还不错），那不是因为它"理解了指令"，而是因为"写一首关于春天的诗"这句话后面，在训练语料里大概率就跟着一首诗，纯粹是概率巧合。

### 经过 SFT 微调的模型

- **能力**：学会了"看到指令就认真回答"的模式
- **表现**：回答更完整、更有条理、更贴合问题
- **本质**：从"续写文本"升级为"遵循指令"

这就是 SFT 的意义——让模型从"会写字"变成"会对话"。
