# Agent 核心架构与工作流程

## Agent 循环机制与异常控制设计

在 Agent 系统的设计中，循环机制是最核心的架构模式。一个典型的 Agent 采用 `while True` 无限循环作为基础框架，通过特定的输出标记来控制循环的终止。这种设计模式确保了 Agent 能够持续地处理任务，直到达到预设的完成条件。

### 异常驱动的流程控制

Agent 领域普遍采用异常控制流程的设计模式，这种方法通过预定义的特殊标记来触发特定的异常，从而实现优雅的程序退出。具体的工作流程如下：

1. Prompt 中预先定义输出规范，要求 LLM 在完成任务时输出特定的标记，如 `COMPLETE_TASK_XXX`
2. LLM 根据指令输出包含标记的内容
3. 代码通过 `has_finished()` 等方法检测到标记后
4. 触发 `Submitted` 异常（继承自 `TerminatingException`）
5. 外层通过 `except TerminatingException` 捕获异常并退出循环

> [!tip] 为什么使用异常而非 return？
> 使用异常控制流程的主要优势在于能够直接跳出多层嵌套的循环，而不需要逐层返回。这在复杂的 Agent 系统中尤为重要，因为可能存在多层的函数调用和循环结构。

## mini-swe-agent 的六步工作流程

mini-swe-agent 作为一个典型的 Agent 实现，其工作流程被精心设计为六个标准步骤，每个步骤都有明确的目标和执行逻辑：

### 1. 代码库分析
Agent 首先需要通过多次执行 `ls`、`find`、`cat` 等命令来探索和理解目标代码库的结构和内容。这个阶段的质量直接影响后续所有步骤的效率。

### 2. 问题复现脚本
创建能够稳定复现目标问题的脚本是解决问题的关键步骤。这不仅有助于验证问题的存在，也为后续的修复验证提供了基准。

### 3. 源代码编辑
在准确定位问题后，Agent 需要编辑相应的源代码文件来解决发现的问题。这一步要求 Agent 具备良好的代码理解和修改能力。

### 4. 修复验证
通过再次运行复现脚本来验证修复方案的有效性。这是确保问题真正得到解决的关键验证步骤。

### 5. 边缘情况测试
为确保修复的鲁棒性，Agent 需要设计并执行各种边缘情况的测试，防止修复引入新的问题。

### 6. 变更提交
最后一步是提交所有的修改，完成整个任务流程。

## Workflow 对 LLM 行为的决定性影响

LLM 的行为模式本质上是由 Prompt 中定义的 Workflow 所决定的。不同的 Workflow 设计会导致执行步数的巨大差异。一个精心设计的 Workflow 能够：

- 提供清晰的执行路径
- 减少不必要的尝试和错误
- 提高 Agent 的执行效率
- 增强任务完成的可预测性

> [!warning] Workflow 设计的重要性
> 在 Agent 系统中，Workflow 的质量直接决定了任务执行的效率和成功率。一个好的 Workflow 应该具有清晰的结构、合理的步骤划分和明确的目标导向。

## Agent 运行模式的配置

在 mini-swe-agent 中，通过修改配置文件可以调整 Agent 的运行模式：

- **confirm 模式**（默认）：Agent 每次执行命令前都需要用户确认，适合调试和学习
- **yolo 模式**：自动执行所有命令，无需确认，适合生产环境和批量处理

这个配置可以通过修改 `mini.yaml` 文件中的 `mode` 参数来实现：

```yaml
mode: yolo  # 从 confirm 改为 yolo 实现自动执行
```

## 输出处理机制的核心设计

Agent 的输出处理机制遵循严格的格式要求，这些要求确保了系统能够正确解析和执行 LLM 的意图：

### 标准输出格式
LLM 的输出必须遵循固定的格式结构，包括思考过程和执行命令两个部分：

```
THOUGHT: 我的思考过程...  # 文本部分，仅用于展示
```bash
actual_command_here       # 命令部分，会被实际执行
```
```

### 最终输出的标记机制
当任务完成时，LLM 必须使用特定的标记来通知系统。这个标记必须满足以下条件：

1. 必须被 ````bash` 代码块包裹
2. 必须包含 `COMPLETE_TASK_AND_SUBMIT_FINAL_OUTPUT` 标记
3. 标记必须位于输出内容的第一行

示例格式：
```bash
echo "COMPLETE_TASK_AND_SUBMIT_FINAL_OUTPUT 最终答案是 42"
```

通过这种严格的设计，Agent 系统能够准确地区分中间过程输出和最终结果，确保任务的正确完成和信息的准确传递。
