# 轮动因子与复合因子计算：量化投资策略评估的核心指标

在量化投资的轮动框架中，**因子**是评估策略表现的关键指标，类似于体检报告中的各项健康指标，用于全面评估策略的"健康状况"。通过科学计算各类因子，投资者能够客观判断不同策略的优劣，为策略选择提供数据支撑。

## 因子基础知识：策略评估的量化指标

因子本质上是一种量化指标，用于衡量和评估投资策略的表现特征。在轮动框架中，我们主要关注三类核心因子：短期动量、长期动量和波动率。这些因子从不同维度反映了策略的历史表现和潜在风险，为策略选择提供多维度的决策依据。

> [!info]
> **因子的作用**：将复杂的策略表现转化为可量化的数值指标，便于客观比较和选择

## 短期动量(bias_10)：捕捉策略近期表现

短期动量衡量策略近期表现是否优于近期的平均水平，是评估策略当前"热度"的重要指标。它反映了策略在最近一段时间内的相对表现强度。

### 短期动量的定义与计算

短期动量的正式定义是：**策略当前表现相对于最近10天平均的偏离程度**。其计算公式为：

```
短期动量 = (当前资金曲线 / 最近10天平均资金曲线) - 1
```

#### 计算示例

假设某个策略的资金曲线情况：
- 过去10天的平均资金曲线：1.05
- 当前资金曲线：1.13

那么短期动量 = (1.13 / 1.05) - 1 = 0.076 = 7.6%

### 短期动量的含义解读

短期动量的数值具有明确的指向意义：
- **正值**：表示近期表现好于近期平均水平，策略处于相对强势状态
- **负值**：表示近期表现差于近期平均水平，策略处于相对弱势状态

> [!tip]
> 短期动量类似于汽车的速度表，告诉我们当前策略的"运行速度"是快于还是慢于近期平均水平。

## 长期动量(bias_250)：评估策略长期表现

长期动量衡量策略当前表现是否优于长期平均水平，反映了策略在较长时间跨度内的稳定性和持续性。

### 长期动量的定义与计算

长期动量的定义是：**策略当前表现相对于过去250天平均的偏离程度**。其计算公式为：

```
长期动量 = (当前资金曲线 / 过去250天平均资金曲线) - 1
```

#### 计算示例

假设某策略的历史表现：
- 过去250天的平均资金曲线：1.20
- 当前资金曲线：1.32

那么长期动量 = (1.32 / 1.20) - 1 = 0.10 = 10%

> [!note]
- **时间跨度的选择**：250天约等于一年的交易日，能够充分反映策略的长期表现特征
- **长期动量的意义**：反映策略的长期稳定性和持续盈利能力

## 波动率(bbw_10)：衡量策略风险特征

波动率衡量策略收益的波动程度，类似收益的"颠簸程度"，是评估策略风险水平的关键指标。在量化投资中，我们采用基于布林带的方法来计算波动率。

### 波动率的定义

波动率的定义是：**策略资金曲线的波动程度**。我们使用布林带宽度(BBW)来量化这个概念。

### 波动率的计算过程

波动率的计算基于布林带理论，包含以下四个步骤：

1. **计算基础数据**：计算最近10天的平均资金曲线和标准差
2. **计算布林带上下轨**：
   - 上轨 = 平均值 + 2倍标准差
   - 下轨 = 平均值 - 2倍标准差
3. **计算布林带宽度**：波动率 = (上轨 - 下轨) / 平均值
4. **简化计算**：波动率 = 4倍标准差 / 平均值

#### 波动率示例

假设某策略最近10天的资金曲线数据：
- 平均资金曲线：1.10
- 标准差：0.0025

那么波动率 = (4 × 0.0025) / 1.10 = 0.0091 = 0.91%

### 波动率的实际含义

波动率4.56%表示所有的数值在平均值的±4.56%范围内波动。数值越小，说明策略表现越稳定；数值越大，说明策略表现波动越剧烈。

> [!warning]
> 波动率本身并不直接等同于风险，但过高的波动率往往伴随着更大的不确定性，需要投资者谨慎对待。

## 波动率排名：相对历史位置的评估

波动率排名是一个相对指标，用于评估当前波动率在历史波动率中的位置。它不是在不同策略之间进行比较，而是策略自己与自己历史的比较。

### 波动率排名的定义与计算

波动率排名的定义是：**当前波动率在过去250天内的排名位置**。计算过程如下：

1. 获取策略过去250天的波动率历史记录
2. 将当前波动率与历史记录进行排名比较
3. 将排名转化为百分比：排名位置 / 250

#### 波动率排名示例

假设策略A的计算结果：
- 当前波动率在过去250天中排名第150位
- 波动率排名 = 150 / 250 = 0.6 = 60%

### 波动率排名的含义解读

波动率排名0.6（60%）意味着：
- 策略A的当前波动率比60%的历史时期都要高
- 当前市场环境相对历史较为波动
- 需要更加关注短期表现

> [!question]
> **为什么波动率排名重要？**
>
> 波动率排名帮助我们理解当前市场环境的相对状态。当波动率排名较高时，说明市场处于相对不稳定的状态，此时应该更加关注策略的短期表现；反之，当波动率排名较低时，市场相对稳定，可以更多关注长期表现。

## 复合因子：多维度综合评估

复合因子是将短期动量和长期动量结合起来，形成更加全面的策略评估指标。通过科学的权重分配，复合因子能够平衡短期机会和长期价值。

### 复合因子的计算公式

```
复合因子 = 短期动量 × 权重 + 长期动量 × (1 - 权重)
```

### 权重的动态确定机制

权重不是固定的，而是根据市场波动程度动态调整：

1. **计算各策略的波动率排名**：
   - 策略A：当前波动率0.074，波动率排名0.6（60%分位）
   - 策略B：当前波动率0.065，波动率排名0.5（50%分位）
   - 策略C：当前波动率0.055，波动率排名0.4（40%分位）

2. **确定波动率权重**：
   ```
   波动率权重 = max(所有策略的波动率排名)
   = max(0.6, 0.5, 0.4) = 0.6
   ```

3. **计算各策略的复合因子**：
   ```
   策略A复合因子 = 策略A短期动量 × 0.6 + 策略A长期动量 × 0.4
   ```

### 权重调整的逻辑

权重调整的核心理念是**根据市场环境动态调整关注点**：

- **市场波动大时**：更关注短期表现（权重较大）
- **市场稳定时**：更关注长期表现（权重较小）

> [!success]
> **所有策略共用同一个权重**：这个权重反映了当前市场环境的整体波动程度，由所有策略中波动率排名的最大值决定，确保了对市场环境的一致性判断。

## 复合因子的完整计算流程

复合因子的计算过程体现了系统化的投资决策思路：

1. **计算各策略的基础因子**：
   - 短期动量（bias_10）
   - 长期动量（bias_250）
   - 波动率（bbw_10）

2. **计算波动率权重**：
   ```
   波动率权重 = max(所有策略的波动率排名)
   ```

3. **计算复合因子**：
   ```
   复合因子 = 短期动量 × 权重 + 长期动量 × (1-权重)
   ```

4. **策略选择**：
   选择复合因子最大的策略作为投资策略

> [!info]
- **数据频率**：所有因子计算都在日线级别上进行，确保数据的精确性和及时性
- **转换必要性**：虽然因子在日线级别计算，但最终需要转换为周线级别数据，因为调仓周期是每周一次

## 总结

轮动因子与复合因子的计算体系为量化投资策略选择提供了科学、客观的评估框架。通过短期动量、长期动量和波动率的综合考量，结合动态权重调整机制，系统能够准确识别当前市场环境下的最优策略，实现真正的**智能轮动**。

这种多维度、动态调整的评估方法，不仅提高了策略选择的准确性，更重要的是适应了市场的变化特性，为投资者在不同市场环境下都能做出最优决策提供了强有力的工具支持。
