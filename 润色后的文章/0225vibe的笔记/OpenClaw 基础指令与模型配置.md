# OpenClaw 基础指令与模型配置

OpenClaw 是一个强大的 AI Agent 框架，掌握其基础指令和模型配置是高效使用的前提。本文将介绍核心的斜杠指令、会话管理机制以及模型配置方法。

## 核心斜杠指令

OpenClaw 提供了简洁的斜杠指令来管理会话和模型。最常用的两个指令是：

- **`/new` 或 `/reset`**：开启一个全新的会话，清空当前对话上下文
- **`/model <id>`**：切换当前会话使用的 AI 模型

## 会话级模型设置

理解 `/model` 指令的生效范围非常重要。当你执行 `/model openai/gpt-5.2` 这样的指令时，设置仅在**当前会话**生效，而非全局配置。这种设计被称为 **session override**（会话覆盖）。

会话切换时的行为规则：
- 执行 `/new` → 新会话回归默认模型
- 执行 `/new <id>` → 新会话使用你指定的模型

> [!tip]
> 这种设计让你可以在不同会话中使用不同模型，而不会互相干扰。比如一个会话用 GPT-4 处理复杂推理，另一个会话用 Claude 处理长文本。

## 默认模型配置

全局默认模型存储在配置文件中，路径为：

```
~/.openclaw/openclaw.json
```

具体字段是 `agents.defaults.model.primary`。当你没有在会话中指定模型时，系统就会使用这个默认值。

## 配置修改建议

修改配置有两种方式：

1. **直接编辑配置文件**：适合批量修改或脚本化配置
2. **使用 `openclaw configure` 命令**：适合交互式修改单个配置项

无论哪种方式，修改后都需要执行 `openclaw gateway restart` 重启网关才能生效。
